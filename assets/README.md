# Assets

Drain-theme shove hand. Light grey, transparent, fingers point +X. Tint in code (blue / red). Pivot is canvas centre.

| File | What |
| --- | --- |
| `hand.png` | Idle / rest. 512×512 RGBA |
| `hand_sheet.png` | 6 frames × 512px, left to right: rest, gather, coil, strike, splay, settle |
| `hand_shove.gif` | Motion preview only (baked on dark). Do not tint. |
| `make_hand.py` | Regenerates the PNGs (needs Pillow) |

Sheet frame width is 512.
